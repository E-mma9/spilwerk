### H2: Waarom je computer traag wordt (top 5, simpel uitgelegd)

1. **Schijf vol (90%+)** — Windows Updates, foto's, downloads. Oplossing: opschonen, verplaatsen naar backup.
2. **Te veel opstart-programma's** — alles start mee op. Oplossing: uitzetten wat je niet nodig hebt (laten zien).
3. **Virus/malware of browser-rommel** — toolbars, nep-antivirus. Oplossing: scannen + verwijderen.
4. **Oude harde schijf (HDD) vs SSD** — uitleg: SSD maakt 3-5× sneller, kost €60-90 + installatie. Alleen adviseren als echt nodig.
5. **Te weinig geheugen (RAM)** — 4GB is krap voor Windows 11. Advies: bijplaatsen of niet, eerlijk.

> Per punt: symptoom → oorzaak in 1 zin → wat ik doe. Geen jargon ("defragmenteren" uitleggen of weglaten).

### H2: Wat kun je zelf proberen (5 minuten)

- Herstart (echt uit, niet slaapstand)
- Schijfopruiming: Instellingen → Opslag → Tijdelijke bestanden verwijderen
- Browser: extensies uitzetten, 1 antivirus houden (geen 2)
- Tip: foto's/backup eerst veiligstellen voordat je wist

Waarschuwing: niet zelf register cleaners draaien — maken meer kapot dan ze fixen.
